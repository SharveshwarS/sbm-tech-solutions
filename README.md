# SBM Tech Solutions

Company website with service pages, project case studies, founder profile and email enquiry flow.

By **Sharveshwar S**.

## Run locally

Use Node.js 24 LTS and npm.

```sh
cd frontend
npm ci
npm run dev
```

Run `npm run build` in `frontend` to create the production frontend.
